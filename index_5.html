映像制作の４０年と、これからの時代へ

映像制作は1980年代から大きな変革を遂げました。フィルムから磁気ベースのVTRやカメラへ、そしてフラッシュメモリーをストレージにしたカメラ・サーバー・編集システムが当たり前になり、ソリューションによってはこの30年でその価格は100分の1にまで下がりました。 クラウドへ移行するソリューションが主流となり、映像フォーマットは高圧縮しても画質が維持されるようになり、クラウドを越えたグローバルネットワークも実現しました。そして今、生成AIをはじめとしたAIの機能が映像制作ソリューションの新たな時代を切り拓こうとしています。 この30年間、映像技術のイノベーションに伴奏してきた当社のコンサルタントが、新たな映像ソリューションによるOMO・DCXの実現に貢献します。

CANTO Dev Log

一行のコードも書かずに——
ツールが生まれた日 Not a single line of code —
the day a tool was born

CANTOは、一行のコードも書かずにClaudeとの対話だけで生まれた音楽プレイヤーです。開発の軌跡を全6弾のブログシリーズで公開しています。 CANTO is a music player born entirely through dialogue with Claude — not a single line of code written by hand. The full development story is told across six blog entries.

CANTO — 概要 CANTO — Overview

ブラウザが、
あなたの音楽スタジオになる。 Your browser becomes
a personal music studio.

CANTOは、インストール不要・単一HTMLファイルで動作する音楽ライブラリプレイヤーです。 ローカルフォルダを指定するだけで、ディレクトリ階層を通過しながら数千のトラックをリスト化。 再生・メタデータ編集・EQ・クリップ抽出まで、すべてをブラウザの中で完結させます。 CANTO is a music library player that runs as a single HTML file — no installation, no dependencies. Simply point it at a local folder and it traverses the entire directory hierarchy to list thousands of tracks. Playback, metadata editing, EQ, and clip export — everything runs inside the browser.

Web-Based No Install JP / EN Single HTML File Local & Online
EQアナライザー（周波数帯域をパーティクルで可視化）/ 検索フィルター / キュー管理 EQ Analyzer (frequency bands visualized as particles) / Search filter / Queue management

主な機能 Key Features

01

フォルダーベース・ライブラリ管理 Folder-Based Library

ローカルフォルダを指定するだけで、ディレクトリ階層を再帰的に走査。数千ファイルのトラックリストを即座に生成します。重複ファイルは DUPES タブで自動検出・通知。 Point at any local folder and CANTO recursively scans the directory tree, generating a track list of thousands of files instantly. Duplicate files are automatically detected and flagged in the DUPES tab.

02

IN/OUT クリップ抽出エクスポート IN/OUT Clip Export

長尺音源・ライブ収録から任意の区間をブラウザ内で切り出し、WAV（ロスレス）またはMP3で書き出せます。会議録・フィールド録音の整理に最適。 Trim any segment from a long recording or live session directly in the browser, then export as WAV (lossless) or MP3. Ideal for meetings, field recordings, and archiving.

03

5バンド EQ ＆ アートなアナライザー 5-Band EQ & Visual Analyzer

SUB / BASS / MID / PRESENCE / BRILLIANCE の5バンド調整にノイズリダクションを搭載。EQアナライザーは周波数帯域をマゼンタからシアン・グリーンへと変化するパーティクルで可視化。見て楽しめる要素として設計されており、プリセット（FLAT / BASS BOOST / VOCAL / ROCK 他）も即座に切り替え可能です。 5-band adjustment (Sub / Bass / Mid / Presence / Brilliance) with noise reduction. The EQ analyzer visualizes frequency bands as particles shifting from magenta through cyan to green — designed to be as enjoyable to watch as it is to use. Presets (Flat / Bass Boost / Vocal / Rock and more) switch instantly.

04

iTunes サーチ対応メタデータ編集 iTunes-Search Metadata Editor

Shazam テキストや iTunes URL を貼り付けるだけで、アーティスト・アルバム・ジャケット画像を自動補完。取得したアートワークはGUI デザインの一部として取り込まれ、曲が変わるたびに背景が切り替わります。インターフェースそのものが、音楽の世界観を映すキャンバスになります。 Paste a Shazam result or iTunes URL and CANTO auto-fills artist, album, and artwork. The cover art is absorbed as part of the GUI design itself — the background shifts with every track, turning the interface into a canvas that reflects the world of each song.

05

内蔵DB ＆ ポータブルデータ管理 Built-in DB & Portable Data

メタデータは IndexedDB に保存され、オリジナルファイルには一切書き込みません。プレイリストは M3U / JSON / Shell / BAT の4形式でエクスポート可能。Play Stats（再生回数）も JSON で外部保存・復元でき、ネットがあればどこでも環境を再現できます。 Metadata is stored in IndexedDB — original files are never modified. Playlists export in M3U / JSON / Shell / BAT formats. Play Stats are also exportable as JSON and fully restorable anywhere with a browser.

06

Play Stats ＆ スマートシャッフル Play Stats & Smart Shuffle

再生回数を自動記録しランキング表示。シャッフルは「ランダム」「よく聴く優先」「あまり聴いていない優先」の3モードを選択可能。聴けば聴くほど賢くなるプレイヤー。 Automatically tracks play counts and displays a ranking. Shuffle offers three modes: random, high-play priority, and low-play priority — a player that gets smarter the more you use it.

07

メディア HUB — 選曲 ZIP エクスポート Media HUB — Selected Tracks ZIP Export

キューやリストから選択した曲をまとめて ZIP ファイルに書き出し、任意のディレクトリへ保存できます。 ファイル名オプションで「先頭トラック番号の削除」「メタデータタイトルをファイル名に使用」「フォルダ構造をフラット化」を自由に組み合わせ可能。 ZIP ファイル名もカスタマイズでき、変換後のファイル名はプレビューでその場で確認できます。 音楽ライブラリの整理・バックアップ・共有に最適なメディア管理ハブ機能です。 Select tracks from any queue or list and export them as a single ZIP archive to any directory. Filename options — remove leading track numbers, use metadata title as filename, flatten folder structure — can be combined freely. The ZIP filename is fully customisable, and a live rename preview shows the result before you generate. The ideal media hub for organising, backing up, or sharing your music library.

CANTO DJ MASTER — 概要 CANTO DJ MASTER — Overview

同じブラウザで、
2つの CANTO が混ざり合う。 Two CANTOs. One browser.
Seamless DJ mixing.

CANTO DJ MASTER は、CANTO をベースにした DJ 特化の拡張版です。 同じブラウザのページ内で CANTO を2つ同時に立ち上げ、 中央の X-FADER でクロスフェードしながら連続再生できます。 インストール不要・単一 HTML ファイル。DJ の本質だけを、ブラウザの中に凝縮しました。 CANTO DJ MASTER is a DJ-focused extension built on CANTO. Run two CANTO decks simultaneously in the same browser page, crossfading between them with the central X-FADER for seamless continuous playback. No installation. Single HTML file. The essence of DJ performance, distilled into a browser.

Dual Deck X-FADER Sync Play No Install Browser-Native
DECK A（左）＋ X-FADER（中央）＋ DECK B（右）— ブラウザ内デュアルデッキ構成 DECK A (left) + X-FADER (centre) + DECK B (right) — dual-deck layout running entirely in the browser

使い方 — 3ステップ How It Works — 3 Steps

01

2つの CANTO デッキを起動 Launch Two CANTO Decks

ブラウザの同一ページ内に DECK A と DECK B が並びます。それぞれ独立したキュー・再生制御・ボリューム調整を持ち、同時に別の楽曲を再生できます。 DECK A and DECK B sit side by side in the same browser page. Each has its own independent queue, playback controls, and volume — playing different tracks simultaneously.

02

X-FADER でクロスフェード Crossfade with the X-FADER

中央の X-FADER スライダーを操作することで、DECK A と DECK B の音量バランスをリアルタイムに調整。なめらかなフェードイン・フェードアウトで曲をつなぎます。SYNC PLAY ボタンで両デッキを同時スタートさせることも可能です。 Drag the central X-FADER slider to balance volume between DECK A and DECK B in real time — smooth fade-in and fade-out transitions between tracks. The SYNC PLAY button starts both decks simultaneously.

03

キュー管理とアートワーク背景 Queue Management & Artwork Backgrounds

各デッキの NEXT QUEUE リストはドラッグ＆ドロップで順序を入れ替え可能。CANTO の iTunes サーチ対応メタデータ編集機能で保存したアートワークが、再生中の曲ごとに GUI 背景として変化します。DJ プレイの流れに合わせて、視覚的にも音楽の世界が切り替わります。 The NEXT QUEUE list on each deck supports drag-and-drop reordering. Artwork saved via CANTO's iTunes-search metadata editor shifts the GUI background with every track — the visual world changes in step with your DJ set.
